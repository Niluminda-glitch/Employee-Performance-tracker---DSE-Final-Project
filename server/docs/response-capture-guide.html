📸 API Response Capture Guide

Complete guide for capturing and downloading API responses from Swagger UI

🎯 Quick Access: You're currently viewing this guide. Open Swagger UI in another tab to follow along!
📸 Method 1: Browser Screenshots
  1. Navigate to Swagger UI: http://localhost:5000/api-docs
  2. Test an endpoint: Click "Try it out" on any endpoint
  3. Execute the request: Fill parameters and click "Execute"
  4. Scroll to response section: View the response body and headers
  5. Take screenshot:
    • Windows: Windows + Shift + S (Snipping Tool)
    • Mac: Cmd + Shift + 4
    • Linux: PrtScn or use screenshot tool

📱 Pro Tip: Use rectangular selection to capture just the response section

💾 Method 2: Copy & Save Response Data
  1. Execute API call in Swagger UI
  2. Locate response body in the response section
  3. Select all response text: Ctrl + A (or Cmd + A on Mac)
  4. Copy the text: Ctrl + C (or Cmd + C on Mac)
  5. Open text editor (Notepad, VS Code, etc.)
  6. Paste and save as .json file
✅ Best for: Saving structured JSON responses for documentation or testing
🔧 Method 3: Browser Developer Tools
  1. Open Developer Tools: Press F12 or Ctrl + Shift + I
  2. Go to Network tab in Developer Tools
  3. Execute API call in Swagger UI
  4. Find the request in the Network tab (look for your endpoint URL)
  5. Click on the request to view details
  6. View Response tab for full response data
  7. Right-click → "Copy response" or "Save as HAR"
💡 Advanced: Network tab shows request/response headers, timing, and full HTTP details
🤖 Method 4: Automated Response Capture

Use our custom script to automatically capture responses:

  1. Open terminal in the server directory
  2. Run capture script:
    node scripts/api-response-capture.js
    Captures all sample endpoints
  3. Or capture specific endpoint:
    node scripts/api-response-capture.js GET /api/users/me
    Captures specific endpoint
  4. Find saved files in server/docs/api-responses/
🎉 Features: Automatic authentication, JSON formatting, markdown reports, timestamps
📋 Method 5: Export OpenAPI Specification
  1. Get JSON specification: http://localhost:5000/api-docs.json
  2. Save the file: Right-click → "Save as" → openapi.json
  3. Import into tools: Use with Postman, Insomnia, or other API tools
  4. Generate documentation: Use with other documentation generators

🔐 Authentication Required

Most endpoints require authentication. Here's how to get started:

  1. Test login endpoint first: POST /api/auth/login
  2. Copy the JWT token from the response
  3. Click "Authorize" button in Swagger UI
  4. Enter token in format: Bearer YOUR_JWT_TOKEN
  5. Now test protected endpoints

📁 File Organization Tips

  • Screenshots: Save with descriptive names like login-response.png
  • JSON files: Use endpoint names like get-users-me.json
  • Organize by date: Create folders like 2024-01-15-api-testing/
  • Include metadata: Note the timestamp, user role, and test scenario
💡 Pro Tips for Better Documentation
  • Test different user roles: Capture responses for employee, supervisor, and manager roles
  • Include error scenarios: Test with invalid data to capture error responses
  • Document edge cases: Test with empty data, missing fields, etc.
  • Add annotations: Use image editing tools to highlight important parts
  • Create comparison views: Show before/after states for update operations
